# Vitrine overview

This directory is the presentation layer of the skill kit.

The Vitrine layer exists to make the skill system:

- fast to inspect
- easy to navigate
- easy to reuse
- easy to present to stakeholders

## Structure

- `README.md`: overview and usage
- `capability-map.md`: project capability map
- `project-showcase.md`: example project showcase

## Quick use

Open the `capability-map.md` file to understand which skills are active in a repo. Then apply the relevant module and stack adapter.
